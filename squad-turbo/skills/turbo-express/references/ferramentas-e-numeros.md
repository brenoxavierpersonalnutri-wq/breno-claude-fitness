# Ferramentas, casos citados e números completos — Turbo Express

## Ferramentas de automação

| Ferramenta | Uso | Custo citado |
|---|---|---|
| **ManyChat** | Automação de resposta a comentário/direct → redireciona pro grupo de WhatsApp | — |
| **Z-API** | Disparo de WhatsApp não oficial — "dispara mensagens infinitas" | R$99/mês, recomendado até ~50-100 msgs/dia por número (evitar bloqueio) |
| **API oficial WhatsApp (via ManyChat)** | Disparo utility a baixo custo, alternativa ao Z-API | ~R$0,07/mensagem categoria utility à época — Meta sinalizou queda pra perto de zero a partir de 1º de novembro daquele ano |
| **Sendflow** | Gestão automática de múltiplos grupos — roteia novos entrantes pra um novo grupo assim que o atual bate o teto de ~250 | Paga, mas pode ser feito manualmente |
| **Make / n8n** | Automação do fluxo captação → planilha → disparo | Leo cita usar mais n8n, já usou Make (gratuito até 1.000 operações/mês) |

**Workaround para bug de link do Instagram/WhatsApp** (citado como situação da época da gravação): em vez de mandar o link do grupo direto (às vezes trava), a automação pede primeiro o nome, depois o telefone — telefone salvo em planilha e disparado via Z-API ou API oficial.
